## 1. محتويات حزمة النشر الجاهزة (`smart-masar-static-hosting.zip`)

عند فك الضغط عن هذا الأرشيف، ستجد الملفات الإنتاجية النهائية الجاهزة للرفع مباشرة إلى أي استضافة ويب قياسية:

```text
├── index.html                  # الصفحة الرئيسية ونقطة الدخول لتطبيق الويب (Production SPA)
├── smart-masar.html            # النسخة المستقلة الموحدة في ملف HTML واحد (تعمل أيضاً بدون ملفات خارجية)
├── assets/
│   ├── index-*.css             # ملفات التنسيق المجمعة والمضغوطة (Tailwind CSS + Arial Typography)
│   ├── index-*.js              # ملفات الجافاسكربت الإنتاجية الخاصة بجميع الصفحات والمكونات
│   └── aistudio/               # الصور والشعارات الرسمية المعتمدة لشركة سمارت مسار
├── .htaccess                   # إعداد التوجيه التلقائي لاستضافات cPanel / Apache المشتركة
├── _redirects                  # إعداد التوجيه التلقائي لمنصات Netlify و Cloudflare Pages
├── vercel.json                 # إعداد التوجيه التلقائي لمنصة Vercel
├── 404.html                    # معالج المسارات التلقائي لمنصة GitHub Pages
└── README.md                   # دليل النشر والتشغيل خطوة بخطوة (هذا الملف)
```

## 2. الصفحات المشمولة في النسخة الإنتاجية

تعمل جميع الصفحات السبع العامة بروابطها المستقلة وبكامل هويتها البصرية وتجاوبها مع الهواتف (390px):
1. **الرئيسية (`/`)**: الهوية البصرية، شعار Road-S، القيمة المضافة، وبطاقات التنقل الأربع.
2. **من نحن (`/about`)**: نبذة الشركة، الرؤية، الرسالة، والقيم المؤسسية الأربع.
3. **خدماتنا (`/services`)**: حلول الذكاء الاصطناعي، تطوير البرمجيات، التحول الرقمي، وأتمتة العمليات (RPA).
4. **فريق العمل (`/team`)**: الكوادر التأسيسية الستة والبحث والتصفية حسب القسم مع نافذة الملف الوظيفي.
5. **الهيكل التنظيمي (`/organization`)**: المخطط الهرمي التفاعلي (المدير العام د. أحمد العابد والأقسام الخمسة التابعة).
6. **الوظائف (`/careers`)**: شاغر "محاسب عام – Accountant" بكافة تفاصيله وربطه بنموذج التقديم عبر Google Forms.
7. **تواصل معنا (`/contact`)**: بيانات الاتصال، ساعات العمل، ونموذج المراسلة.

## 3. خطوات النشر خطوة بخطوة (بدون بطاقة ائتمان أو Google Cloud Billing)

### الخيار الأول (الأسرع والأسهل): النشر عبر Netlify Drop أو Tiiny.host (خلال 30 ثانية)
1. قم بفك ضغط ملف `smart-masar-static-hosting.zip` في مجلد على جهازك.
2. افتح موقع [app.netlify.com/drop](https://app.netlify.com/drop) أو [pages.cloudflare.com](https://pages.cloudflare.com).
3. اسحب المجلد الذي فككت ضغطه وأفلته داخل المتصفح.
4. ستحصل فوراً على **رابط عام مجاني ومؤمّن (HTTPS)** يعمل على جميع الهواتف وأجهزة الكمبيوتر، ويتكفل ملف `_redirects` المرفق بتشغيل جميع الروابط (`/about`, `/services`, `/team`, إلخ).

### الخيار الثاني: النشر المجاني عبر GitHub Pages
1. أنشئ مستودعاً عاماً (Public Repository) جديداً على حسابك في GitHub.
2. ارفع جميع الملفات الموجودة داخل الحزمة (`index.html`, مجلد `assets/`, `404.html`, `smart-masar.html`, إلخ) إلى جذر المستودع.
3. من إعدادات المستودع (**Settings** -> **Pages**)، اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
4. سيعمل الموقع عبر رابط GitHub Pages العام، ويتكفل ملف `404.html` المرفق بدعم التنقل المباشر بين الصفحات.

### الخيار الثالث: النشر على استضافة مشتركة (cPanel / Hostinger / Apache)
1. ادخل إلى لوحة تحكم الاستضافة (cPanel) وافتح **مدير الملفات (File Manager)**.
2. انتقل إلى مجلد `public_html`.
3. ارفع ملف `smart-masar-static-hosting.zip` وقم بفك الضغط عنه داخل `public_html` مباشرة (تأكد أن `index.html` ومجلد `assets` وملف `.htaccess` موجودة في جذر `public_html`).
4. افتح رابط نطاقك العام؛ سيعمل الموقع بالكامل بفضل قواعد `RewriteRule` المجهزة داخل `.htaccess`.

### الخيار الرابع: تشغيل ملف HTML المستقل الواحد (`smart-masar.html`)
* إذا كانت الاستضافة تدعم رفع ملف HTML واحد فقط (أو أردت مشاركة الموقع كملف واحد عبر البريد أو الواتساب)، استخدم ملف **`smart-masar.html`** المرفق.
* يمكنك إعادة تسميته إلى `index.html` ورفعه بمفرده؛ فهو يضم الهيكل والتنسيقات والبرمجة والبيانات التأسيسية والربط القرائي مع SheetDB داخل ملف واحد مستقل تماماً.

## 4. توضيح تقني صادق: ما الذي يعمل على استضافة HTML/CSS/JS وما الذي يحتاج خادماً خلفياً؟

حرصاً على الشفافية الهندسية وأمان المشروع، تم فصل الموقع العام عن العمليات الإدارية الحساسة كالتالي:

| الميزة / الوظيفة | هل تعمل على استضافة HTML/CSS/JS ثابتة؟ | التوضيح التقني |
| :--- | :---: | :--- |
| **تصفح جميع الصفحات الـ 7 والتنقل المتجاوب** | **نعم (100%)** | تعمل بالكامل عبر HTML وCSS وJavaScript المجمعة دون الحاجة لأي خادم. |
| **عرض الموظفين الـ 6، الأقسام الـ 5، والهيكل التنظيمي** | **نعم (100%)** | البيانات التأسيسية مدمجة بالكامل وتعمل فوراً حتى في حال انقطاع الاتصال. |
| **عرض شاغر المحاسب والتقديم عبر Google Forms** | **نعم (100%)** | زر التقديم يحول المتقدم مباشرة إلى استمارة Google Forms العامة الخاصة بالشاغر. |
| **قراءة التحديثات الحية من Google Sheets عبر SheetDB** | **نعم (قراءة عامة)** | يتصل الموقع العام تلقائياً بواجهة القراءة العامة لـ SheetDB (`GET https://sheetdb.io/api/v1/gnn52l70oflrp`) لجلب أي تحديثات منشورة في أوراق الجدول الست دون كشف أي مفاتيح سرية. |
| **حماية مفاتيح الإدارة والبيانات السرية** | **نعم (100%)** | لا يحتوي ملف `index.html` أو ملفات JavaScript العامة على أي كلمات مرور أو مفاتيح إدارة سرية (`SMART_MASAR_ADMIN_KEY`). |
| **التعديل الإداري وحفظ التغييرات الدائمة (Admin CRUD)** | **تحتاج خادماً خلفياً أو Google Apps Script** | استضافة HTML/CSS/JS الثابتة لا تمتلك قاعدة بيانات كتابية محلية (`db.json`). لحفظ تعديلات الإدارة بأمان دون كشف المفاتيح للجمهور، يلزم تشغيل خادم Node.js (`server.ts` على Render أو Railway مثلاً) أو ربط تطبيق الويب الخلفي المجاني **Google Apps Script**. |
| **رفع الصور وحفظها في Google Drive أو الخادم** | **تحتاج Google Apps Script أو خادماً خلفياً** | رفع ملفات الصور والتحقق من صلاحية المسؤول يتطلب خدمة خلفية؛ ويمكن تشغيله مجاناً بدون Google Cloud Billing عبر نشر ملف `backend/google-apps-script.js` كـ Web App مجاني في حساب Google الخاص بك. |

## 5. كيفية تفعيل Google Sheets و Google Drive مجاناً (بدون Google Cloud Billing)

إذا رغبت بتفعيل رفع الصور إلى Google Drive وتحديث الجداول من لوحة الإدارة دون دفع أي رسوم سحابية:
1. افتح ملف Google Sheets المرتبط بـ SheetDB (`https://sheetdb.io/api/v1/gnn52l70oflrp`).
2. من القائمة العلوية اختر **Extensions (الإضافات)** -> **Apps Script**.
3. الصق الكود الموجود في ملف `backend/google-apps-script.js` (المتوفر في أرشيف المشروع الكامل).
4. شغّل دالة `initialSetup` مرة واحدة لإنشاء الأوراق الست (`Team`, `Services`, `Pages`, `SiteSettings`, `Departments`, `Jobs`).
5. اضغط **Deploy** -> **New deployment** واختر النوع **Web app** لتعمل الخدمة مجاناً بالكامل على حساب Google العادي دون الحاجة إلى تفعيل فوترة Google Cloud.
